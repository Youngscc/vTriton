# Agent Context

This directory contains project context intended for AI agents and automation.
Use `AGENTS.md` as the top-level operating guide, then read only the files here
that are relevant to the current task.

- `project-context.md`: project goals, scope, inputs, outputs, and boundaries.
- `architecture.md`: cross-module architecture, data flow, and entrypoints.
- `terminology.md`: domain concepts, metrics, names, and units.
- `decisions.md`: durable design decisions and conventions.
- `known-issues.md`: confirmed limitations, unresolved issues, and workarounds.
- `implementation-status.md`: feature completion and validation status.

Human-facing documentation remains under `docs/`.
